# Aktuality

Každá novinka je jeden soubor `.md` v `cs/` a `en/`.

```markdown
---
title: Nová sauna v rezidenci
date: 2026-09-18
---

Text novinky. Odstavce se oddělují prázdným řádkem.
```

Sekce Aktuality se na webu **zobrazí jen tehdy, když tu nějaká novinka je**
a není starší než rok. Prázdná nebo zastaralá sekce novinek působí hůř,
než kdyby tam nebyla.
